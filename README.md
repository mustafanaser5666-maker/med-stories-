# 🩺 حكيم الأطفال - مولد ستوريات طب الأطفال باللهجة العراقية
### د. مصطفى الحسيني | أخصائي طب الأطفال وحديثي الولادة (`@dr.er11`)

تطبيق ويب متكامل مصمم خصيصاً لأطباء الأطفال وصناع المحتوى الطبي في العراق لتوليد وتصميم **ستوريات إنستغرام (Instagram Stories)** توعوية وتفاعلية بمقاس 9:16 وبدقة عالية، باستخدام الذكاء الاصطناعي مع رسوم كرتونية جذابة وملصقات تفاعلية مصاغة باللهجة العراقية اللطيفة والمطمئنة للأمهات والآباء.

---

## ✨ المميزات الرئيسية

1. **مولد ستوريات بالذكاء الاصطناعي (AI Pediatric Story Generator)**:
   - توليد سلايدات طبية متسلسلة باستخدام نموذج Google Gemini (`gemini-3.8-flash`).
   - صياغة موجهة للأمهات العراقيات بالعامية البغدادية اللطيفة لتصحيح الخرافات الشائعة وتقديم الإرشادات الطبية المعتمدة.
   - مكتبة مواضيع جاهزة:
     - 🌡️ **الصخونة عند الرضيع**: الكمادات الصح، جرعة البراسيتول بالوزن، وعلامات الخطر.
     - 🦷 **التسنين وشگ السن**: العضاضة المبردة ومنع جل التسنين المخدر.
     - 🍼 **المغص والغازات**: تكنيك التكريع السليم ومساج البطن وتجنب الأعشاب.
     - 🥣 **أكل الرضيع بالشهر السادس**: علامات الجاهزية وقاعدة الـ 3 أيام وقائمة الممنوعات.
     - 💉 **اللقاحات والحرارة**: علاج التورم وتجنب الخافض قبل الإبرة.

2. **كانفاس إنستغرام ستوري حقيقي (9:16 Canvas)**:
   - شريط ستوري متعدد السلايدات بأعلى الشاشة مع شارة التوثيق الزرقاء `✓`.
   - ملصقات تفاعلية حقيقية:
     - تصويت (Poll)
     - كويز واختبار سريع (Quiz)
     - صندوق أسئلة ومشاركات (Question Box)
     - مقياس الإيموجي (Slider)
   - 6 ثيمات ألوان مريحة لعيادات الأطفال (نعناعي طبي، وردي مريح، سماوي طفولي، عسلي دافئ، بنفسجي خزامى، وليلي كحلي).

3. **استوديو الرسوم الكرتونية والصور التوضيحية (Cartoon Studio)**:
   - حزمة رسوم كرتونية حصرية مبهجة لطب الأطفال:
     - شخصية د. مصطفى الحسيني الكرتونية بالسماعة والبالطو الطبي.
     - طفل مصخن بملابس دافئة وكمادات ومحرار لطيف.
     - طفل يأكل وجبته الصحية الأولى بكرسي الطعام.
     - طفل نائم بسلام بين النجوم والقمر.
   - إمكانية توليد رسوم كرتونية جديدة بحسب الطلب بواسطة الذكاء الاصطناعي (`gemini-3.1-flash-lite-image`).
   - إمكانية رفع لوجو العيادة أو صور خاصة من الجهاز.

4. **تصدير ومعاينة تفاعلية**:
   - تحميل فوري عالي الدقة بصيغة **PNG** جاهز للنشر المباشر.
   - وضع المعاينة التلقائي (Instagram Live Player) مع مؤقت 5 ثوانٍ لكل سلايد.
   - نسخ الكابشن والهاشتاغات العراقية بضغطة زر.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide Icons, Canvas Confetti, HTML-to-Image.
- **Backend**: Node.js, Express, TSX.
- **AI Models**: Google GenAI SDK (`@google/genai`):
  - `gemini-3.8-flash`: توليد المحتوى الطبي والستوريات والملصقات التفاعلية.
  - `gemini-3.1-flash-lite-image`: توليد الرسوم الكرتونية الطبية للأطفال.

## 🚀 التشغيل المحلي (Getting Started)

### 1. استنساخ المستودع (Clone)
```bash
git clone https://github.com/mustafanaser5666-maker/med-stories-.git
cd med-stories-
```

### 2. تثبيت الحزم (Install Dependencies)
```bash
npm install
```

### 3. إعداد مفتاح البيئة (Environment Variables)
قم بإنشاء ملف `.env` وإضافة مفتاح Gemini API:
```env
GEMINI_API_KEY="your_gemini_api_key_here"
PORT=3000
```

### 4. تشغيل السيرفر المحلي
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`
